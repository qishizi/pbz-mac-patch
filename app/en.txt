FSR 4 upscaling
When on, choosing DLSS in the game runs FSR 4 instead of MetalFX. The image is usually better, but the GPU works harder and the frame rate drops, so it is off by default. NotProton only.
Install Xcode 26 or later, then run xcodebuild -downloadComponent MetalToolchain in Terminal.
When the items below are ticked, click “Turn on FSR 4”, then start the game. The launch options stay the same.
In the game, set the upscaler to DLSS. On the first run FSR 4 compiles shaders and the game freezes for ten seconds or so.
The FSR 4 panel opens with the game; you can adjust sharpness there. If the game stays on the warning screen, click the game window.

Lossless frame generation
Uses Lossless Scaling's frame generation to turn about 60 fps into about 120 fps. NotProton only.
Buy Lossless Scaling on Steam (paid software; the patch cannot include its files) and have its Lossless.dll in your Steam library, or put it at ~/lsfg/lsfg-vk.dll.
Install LsfgInjector and open it once so it prepares the files in ~/lsfg.
When both items below are ticked, click “Turn on frame generation”, then start the game.
Turn off frame generation in the game; keep only one.
